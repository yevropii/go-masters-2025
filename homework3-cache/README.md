## Задание

Разработать структуру данных и набор методов, реализующих обобщённый кэш в виде набора ключ-значение.

### Требования

- Кэш должен быть безопасным для конкурентного использования.
- Ключ должен быть любым, удовлетворяющим интерфейсу `comparable`.
- Значение может быть любым (`any`).

### API

- `New()` – конструктор.
- `Cache.Get(key)` – получение значения по ключу.
- `Cache.Set(key, value)` – установка значения по ключу.
