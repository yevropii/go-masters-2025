## Задание

Написать http-сервер в виде одного файла с одним обработчиком, который бы принимал запрос вида: GET http://localhost:8080/fibo?N=10

### Требования

- обработчик должен вычислять число Фибоначчи для переданного запроса и возвращать результат пользователю
- Для теста обработчика используйте пакет "net/http/httptest"
- Нужно написать табличный тест для вычисления числа Фибоначчи
- Нужно написать тест для самого обработчика HTTP-запроса
